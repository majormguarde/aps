# Реквизиты

Справочник обязательных и опциональных реквизитов документов.

## Организация

| Поле | Тип | Обязательное | Описание |
|------|-----|--------------|----------|
| `inn` | string(10\|12) | да | ИНН организации |
| `kpp` | string(9) | нет | КПП (для юр. лиц) |
| `ogrn` | string(13\|15) | да | ОГРН / ОГРНИП |
| `name` | string | да | Полное наименование |

## Банковские реквизиты

| Поле | Тип | Обязательное | Описание |
|------|-----|--------------|----------|
| `bik` | string(9) | да | БИК банка |
| `account` | string(20) | да | Расчётный счёт |
| `corr_account` | string(20) | да | Корреспондентский счёт |

## Документ

| Поле | Тип | Обязательное | Описание |
|------|-----|--------------|----------|
| `number` | string | да | Номер документа |
| `date` | date | да | Дата документа |
| `amount` | decimal | да | Сумма |
| `currency` | string(3) | да | Код валюты (ISO 4217) |
