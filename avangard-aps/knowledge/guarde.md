# Guarde — правила и ограничения

Базовые правила обработки документов в системе Avangard APS.

## Общие принципы

- Все входящие данные проходят валидацию по схеме
- Критические ошибки блокируют дальнейшую обработку
- Предупреждения фиксируются в отчёте, но не останавливают процесс

## Категории проверок

| Категория | Описание |
|-----------|----------|
| `required` | Обязательные поля и реквизиты |
| `format` | Формат значений (ИНН, даты, суммы) |
| `consistency` | Согласованность между связанными полями |
| `business` | Бизнес-правила предприятия |
