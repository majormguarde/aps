# Архитектура Avangard APS

## Обзор

Avangard APS (Automated Processing System) v5 — модульная система валидации, проверки и обработки документов.

## Структура проекта

```
avangard-aps/
├── aps/          # Ядро: схемы, правила, проверки, валидаторы, действия
├── knowledge/    # База знаний: правила, реквизиты, примеры
├── templates/    # HTML-шаблоны отчётов и документов
├── make/         # Сценарии сборки и промпты
└── docs/         # Документация
```

## Поток обработки

```mermaid
flowchart LR
    Input[Входные данные] --> Schema[Схема]
    Schema --> Validators[Валидаторы]
    Validators --> Checks[Проверки]
    Checks --> Rules[Правила]
    Rules --> Actions[Действия]
    Actions --> Output[Результат]
```

## Компоненты

| Компонент | Назначение |
|-----------|------------|
| `schema/` | JSON/YAML-схемы структуры данных |
| `validators/` | Проверка формата и типов полей |
| `checks/` | Бизнес-проверки и ограничения |
| `rules/` | Правила принятия решений |
| `actions/` | Действия по результатам проверок |
| `tests/` | Тесты для всех компонентов |

## Конфигурация

Точка входа — `aps/aps-v5.yaml`. Все пути к модулям задаются относительно этого файла.
