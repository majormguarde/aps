# Руководство разработчика

## Быстрый старт

1. Клонируйте репозиторий
2. Ознакомьтесь с `aps/aps-v5.yaml` — основной конфигурационный файл
3. Изучите `knowledge/guarde.md` и `knowledge/rekvizity.md`

## Добавление новой проверки

1. Создайте файл в `aps/checks/`
2. Зарегистрируйте проверку в `aps/aps-v5.yaml`
3. Добавьте тест в `aps/tests/`

## Добавление валидатора

1. Создайте файл в `aps/validators/`
2. Привяжите к полям схемы в `aps/schema/`

## Шаблоны

HTML-шаблоны в `templates/` используют плейсхолдеры вида `{{ field }}`.

- `report.html` — отчёты о результатах обработки
- `invoice.html` — счета на оплату

Стили и скрипты — в подкаталогах `css/` и `js/`.

## Сценарии сборки

Каталог `make/scenarios/` содержит сценарии автоматизации.
Каталог `make/prompts/` — промпты для AI-ассистентов.

## Тестирование

Тесты располагаются в `aps/tests/`. Каждый тест должен покрывать один компонент (check, validator, rule или action).
